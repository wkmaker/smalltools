DNS HTTPS 紀錄 (Type 65) 設定產生器

免費線上工具，支援 RFC 9460 規範之服務模式 (Service Mode) 與別名模式 (Alias Mode)。透過視覺化勾選與填空即時產生完整 HTTPS 紀錄，並提供各大 DNS 代管商 (Cloudflare、AWS Route53 等) 對照填寫指南。

設定參數 (勾選與填空)
常用預設情境 (點擊快速帶入)：
服務模式 (Service Mode) Priority > 0，自訂 ALPN / Port / IP
別名模式 (Alias Mode) Priority = 0，類似 CNAME 轉向
SvcParams 服務參數配置
產出紀錄與 DNS 代管商填寫對照
完整 BIND / RFC 9460 格式紀錄
example.com. 300 IN HTTPS 1 . alpn="h2,h3"
DNS 管理介面【4大核心欄位】對照表
1. 名稱 (Name / Host)
@
子網域或 `@` (根網域)。代管商會自動補齊主網域。
2. 優先順序 (Priority / SvcPriority)
1
整數值。`0` 代表別名模式；`1` 以上代表服務模式。
3. 目標 (Target / TargetName)
.
填入 `.` 代表目標為本網域本身；亦可填寫指定 FQDN。
4. 值 / 內容 (Value / SvcParams)
alpn="h2,h3"
各項 SvcParams 參數（如 ALPN、IP 提示等）。別名模式時為空。
